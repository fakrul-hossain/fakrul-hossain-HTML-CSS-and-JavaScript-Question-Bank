# HTML, CSS, and JavaScript Question Bank

## Part 1: HTML (20 Questions)

### 1. Semantic Tags

1. **What are semantic HTML tags, and why are they important?**  
   - Semantic HTML tags give meaning to the content, making it easier for browsers and developers to understand the structure.

2. **Name five commonly used semantic HTML tags and their purposes.**  
   - `<header>` - Defines introductory content.  
   - `<footer>` - Contains footer information.  
   - `<article>` - Represents independent content.  
   - `<section>` - Groups related content.  
   - `<aside>` - Contains additional or side content.

3. **How does `<article>` differ from `<section>`?**  
   - `<article>` represents a self-contained piece of content, while `<section>` is a generic section of a document.

4. **Why should we use `<figure>` and `<figcaption>` in HTML?**  
   - `<figure>` is used to group media elements, and `<figcaption>` provides a caption for the media.

---

### 2. Attributes

5. **What is the difference between global and specific attributes in HTML?**  
   - Global attributes apply to all elements, while specific attributes are limited to certain elements.

6. **Explain the purpose of the `alt` attribute in an `<img>` tag.**  
   - The `alt` attribute provides alternative text for images, improving accessibility and SEO.

7. **How does the `href` attribute work in an `<a>` tag?**  
   - It specifies the URL or location the link points to.

8. **What does the `target="_blank"` attribute do in a link?**  
   - It opens the link in a new tab.

---

### 3. HTML Elements

9. **What is the difference between block-level and inline elements?**  
   - Block-level elements take up the full width, while inline elements only take up as much width as necessary.

10. **Explain the difference between `<div>` and `<span>`.**  
    - `<div>` is a block-level container, while `<span>` is an inline container.

11. **What is the `<meta>` tag used for in HTML?**  
    - It provides metadata about the document, such as charset, author, and viewport settings.

12. **Why should we use the `<head>` element in an HTML document?**  
    - It contains metadata and links to external resources like stylesheets and scripts.

---

### 4. Forms and Inputs

13. **What is the purpose of the `<form>` element in HTML?**  
    - It is used to collect user input and submit it to a server.

14. **What are the different types of `<input>` elements in HTML forms?**  
    - Text, email, password, number, checkbox, radio, file, submit, etc.

15. **How can we make a form input field required?**  
    - By adding the `required` attribute to the `<input>` element.

16. **What is the difference between `<button>` and `<input type="submit">`?**  
    - `<button>` is more flexible and can contain HTML, while `<input type="submit">` only submits forms.

---

### 5. Media

17. **How can you embed an audio file in HTML?**  
    - Using the `<audio>` tag with the `controls` attribute.

18. **What is the purpose of the `<video>` tag in HTML?**  
    - It allows embedding of video content in a webpage.

19. **How can you add captions to a video in HTML?**  
    - Using the `<track>` tag within the `<video>` element.

20. **What is the difference between the `<iframe>` and `<embed>` elements?**  
    - `<iframe>` is used for embedding external web pages, while `<embed>` is used for media files.
